# MVT Entrenamientos

Aplicación web desarrollada con Vue 3, TypeScript y Firebase Firestore para registrar entrenamientos.

## Funcionalidades

- Registrar entrenamientos.
- Editar entrenamientos.
- Eliminar entrenamientos.
- Visualización en tiempo real mediante Firestore.

## Tecnologías

- Vue 3
- TypeScript
- Firebase Firestore
- Firebase Hosting
- Vite

## Instalación

```bash
npm install
```

## Ejecutar el proyecto

```bash
npm run dev
```

## Generar la versión de producción

```bash
npm run build
```

## Despliegue

```bash
firebase deploy
```
